## More experiments

- [CodeBeez AI Phone Agent](https://github.com/aredwan-xyz/codebeez-ai-phone-agent): voice-agent prototype integrating telephony, speech and tools. Latency is a target pending benchmarks.
- [CodeBeez AI Autopilot](https://github.com/aredwan-xyz/codebeez-ai-autopilot): business-agent framework under development; integrations require configuration and validation.
- [Video Autopilot](https://github.com/aredwan-xyz/video-autopilot): a video-generation pipeline with an opt-in publisher. A successful build and a published video are separate outcomes.

- [JARVIS](https://github.com/aredwan-xyz/jarvis-os): a local assistant prototype using keyword routing and demo integrations.
